## 2. Corrections the design must adopt

1. **Budget tokens per OS.** Treat 4,096 tokens as the floor (26.x and older Apple Intelligence devices). Read `contextSize` at runtime (26.4+) rather than hard-coding ~4K or 8K. Keep chunking.
2. **Treat PCC as an optional, revocable tier.** Gate it behind the entitlement, SBP status and the <2M-download ceiling. Handle offline use and daily-limit exhaustion with a fallback to the on-device model or a non-AI path. Never make it core functionality: Apple says fees are coming, and outgrowing the threshold forces a migration within 6 months.
3. **Third-party models (Claude/Gemini packages) mean your own backend for keys and billing**, plus disclosure and explicit consent under 5.1.2(i) ("including with third-party AI"). That conflicts with the privacy-first story, so keep them off by default.
4. **Drop `WKExtendedRuntimeSession` for "focus sessions" unless a session type honestly fits.** Mindfulness (1h, frontmost) is the only plausible one and is meant for meditation. Use the iPhone Live Activity in the Watch Smart Stack and a Watch control instead.
5. **Notifications: each platform's app schedules its own local notifications from synced data.** The Mac app suppresses relayed iPhone notifications for the same app. iPad gets no relay. Watch forwarding is deduped by the system. Do not design on "Apple ID relay".
6. **Widget actions don't run on a locked device without authentication.** Don't promise lock-screen one-tap completion. Watch accessory widgets are not listed as interactive; use a Watch control for one-tap actions.
7. **Live Activities:** the 8h/12h limits are real. Also use `LiveActivityIntent` so a Control or Shortcut can start a focus session from the background. Scheduled starts require an alert configuration (verify the availability range, since the metadata reads "26.0 – 26.0").
8. **Reminders integration requires full Reminders access.** There is no write-only option, so a lighter "export to Calendar" path should use write-only events or EventKitUI (no prompt).
9. **Family Sharing is irreversible per product.** Decide before enabling it on "Plus". Family Sharing covers subscriptions and non-consumables only.
10. **App Review constraints on accountability features:** money-at-risk contracts run into 5.3 (real-money gaming licensing, no IAP credit) and 3.1.1, so drop them. Paid features can't require check-ins or social posts (3.1.2(a)) or data-access grants (5.1.1(ii)). Promotional nudges need opt-in, and push can never be required (4.5.4, 5.1.2(i)). Subscriptions need ≥7-day periods, "ongoing value" and access on all the user's devices.
11. **MCP:** the Xcode 26.3 MCP has nothing to do with app users. For apps, the Apple-supported agent surface in 27 is App Intents with **App Schemas**. Keep the local Mac MCP helper as an optional, self-built extra.
12. **Fix the citation.** Stop citing forum 809361 as evidence of Apple's position.

## 3. Apple capabilities research.md missed (fit for a non-boring task/event/accountability app)

- **App Schemas, `.reminders` domain (27):** create, update ("Mark this reminder as completed") and delete reminders, lists and sections, plus a `locationTrigger` entity. Siri handles natural language with no custom phrases, so this is the highest-leverage Siri work. The calendar domain suits event mode. [Reminders domain](https://developer.apple.com/documentation/appintents/app-schema-domain-reminders)
- **View Annotations API (27):** maps on-screen views to entities so users can say "push this to tomorrow" about what they are looking at. [iOS 27 guide](https://developer.apple.com/wwdc26/guides/ios/)
- **AlarmKit (iOS/iPadOS 26):** prominent alarms and countdowns with snooze and a system Live Activity. A strong "start now" commitment cue, opt-in only. [AlarmKit](https://developer.apple.com/documentation/alarmkit)
- **RelevanceKit relevant widgets (watchOS 26):** Smart Stack cards keyed to time or point-of-interest categories, e.g. "at the grocery store: 3 errands". This is the if-then cue made ambient. [WWDC25 334](https://developer.apple.com/videos/play/wwdc2025/334/)
- **iPhone-app controls on Watch without a Watch app (watchOS 26):** a cheap path to Watch presence before a full watch app.
- **Live Activities on Mac menu bar (macOS 26) and CarPlay:** a focus hourglass that follows the user. [ActivityKit](https://developer.apple.com/documentation/activitykit)
- **Foundation Models extras (27):** image input (photo of a paper list becomes tasks), Vision OCR tools, the model on watchOS 27, and the **Evaluations** framework for regression-testing AI breakdowns. [WWDC26 241](https://developer.apple.com/videos/play/wwdc2026/241/)
- **App Intents Testing framework (27):** test Siri, Shortcuts and widget paths without UI automation.
- **EventKitUI with no permission prompt:** add a task's time block to the calendar with zero privacy friction.
